# 🚀 EnglishEngineer: Mühendisler İçin Duolingo Dönüşüm Master Planı (v1.0)

## 1. PROJE VİZYONU VE HEDEF
Mevcut englishengineer projesini, statik bir kelime listesinden çıkarıp; **10 Mühendislik Dalı** ve **15 Dil** desteği sunan, **Oyunlaştırılmış (Gamified)**, **AI Destekli**, **Kişisel İlerleme Takipli** bir "Mühendisler için Duolingo" platformuna dönüştürmek.

**Temel Farklar:**
- **Statik Liste → Dinamik Dersler:** Kullanıcı sadece kelime okumaz, interaktif alıştırmalar yapar.
- **Sınırsız Erişim → Kademeli İlerleme:** Tüm içerik aynı anda açık değil, seviye seviye (Unit > Level) kilitli olur.
- **Pasif Öğrenme → Aktif Pratik:** AI, kullanıcının yazdığını ve söylediğini anlık düzeltir.
- **Hafızasız → Kalıcı Profil:** XP, Streak (Seri Gün), Can (Heart) ve Rozetler veritabanında saklanır.

---

## 2. TEKNİK MİMARİ VE STACK
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide React (İkonlar).
- **Backend & DB:** Supabase (PostgreSQL, Auth, Realtime, Edge Functions).
- **AI Engine:** OpenAI API (GPT-4o-mini) veya Gemini 1.5 Flash (Düşük maliyet, yüksek hız).
- **State Management:** Zustand (Global state: XP, Can, Streak, Mevcut Ders).
- **Deployment:** Vercel (Frontend), Supabase (Backend).

## 3. VERİTABANI ŞEMASI (SUPABASE)
*Aşağıdaki SQL kodları Supabase SQL Editor'de çalıştırılarak tablolar oluşturulacaktır.*

### 3.1. Users Profile (Kullanıcı Profili)
Kullanıcının oyun istatistiklerini tutar.
\\\sql
CREATE TABLE profiles (
  id UUID REFERENCES auth.users NOT NULL PRIMARY KEY,
  username TEXT UNIQUE,
  full_name TEXT,
  avatar_url TEXT,
  discipline TEXT NOT NULL, -- 'civil_engineering', 'architecture' vb.
  target_language TEXT DEFAULT 'en',
  xp_total INT DEFAULT 0,
  gems INT DEFAULT 0,
  streak_count INT DEFAULT 0,
  last_activity_date DATE DEFAULT CURRENT_DATE,
  hearts INT DEFAULT 5, -- Maksimum 5 can
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
\\\

### 3.2. Units & Levels (Öğrenme Yolu Haritası)
Duolingo tarzı yol haritası yapısı.
\\\sql
CREATE TABLE units (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL, -- 'Ünite 1: Temel İnşaat Terimleri'
  description TEXT,
  order_index INT NOT NULL,
  discipline TEXT NOT NULL,
  color_hex TEXT DEFAULT '#58CC02' -- Duolingo yeşili
);

CREATE TABLE levels (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  unit_id BIGINT REFERENCES units(id),
  title TEXT NOT NULL, -- 'Seviye 1: Merhaba Dünya'
  order_index INT NOT NULL,
  xp_reward INT DEFAULT 10,
  question_count INT DEFAULT 5,
  is_locked BOOLEAN DEFAULT TRUE
);
\\\

### 3.3. User Progress (Kullanıcı İlerlemesi)
Hangi kullanıcı hangi seviyeyi geçti?
\\\sql
CREATE TABLE user_progress (
  user_id UUID REFERENCES profiles(id),
  level_id BIGINT REFERENCES levels(id),
  status TEXT CHECK (status IN ('locked', 'active', 'completed')),
  stars INT DEFAULT 0, -- 0-3 arası yıldız
  completed_at TIMESTAMP WITH TIME ZONE,
  PRIMARY KEY (user_id, level_id)
);
\\\

### 3.4. Questions & Answers (Sorular Havuzu)
Her seviye için dinamik veya statik sorular.
\\\sql
CREATE TABLE questions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  level_id BIGINT REFERENCES levels(id),
  type TEXT CHECK (type IN ('multiple_choice', 'fill_blank', 'speaking', 'writing', 'listening')),
  prompt_text TEXT NOT NULL, -- Soru metni
  prompt_audio_url TEXT, -- Dinleme soruları için
  correct_answer TEXT NOT NULL,
  options_json JSONB, -- Çoktan seçmeli şıklar ["A", "B", "C", "D"]
  ai_evaluation_prompt TEXT -- AI'a gönderilecek özel talimat (Writing/Speaking için)
);
\\\

## 4. OYUNLAŞTIRMA ALGORİTMALARI (GAME LOGIC)

### 4.1. Can Sistemi (Hearts)
- Başlangıç: 5 Can.
- Yanlış Cevap: -1 Can.
- Can 0 olursa: Ders kilitlenir. "Can Doldur" butonu çıkar (Reklam izleyerek veya 24 saat bekleyerek dolar).
- Doğru Cevap: Can artmaz (Sadece doluluk korunur).

### 4.2. Seri Gün (Streak) Mantığı
- \last_activity_date\ kontrol edilir.
- Eğer \	oday > last_activity_date + 1 day\: Streak sıfırlanır.
- Eğer \	oday == last_activity_date + 1 day\: Streak +1 artırılır.
- Görsel: Dashboard'da alev ikonu 🔥 yanında sayı gösterilir.

### 4.3. XP ve Seviye Atlama
- Her doğru cevap: +10 XP (Kolay), +15 XP (Zor).
- Ders Bitimi: Bonus +20 XP.
- Seviye Barı: \xp_total % 100\ hesabıyla doldurulur. Dolunca yeni rozet kazanılır.

### 5.3. State Yönetimi (Zustand Store)
\src/store/gameStore.ts\ dosyası oluşturulacak:
\\\	ypescript
import { create } from 'zustand';

interface GameState {
  hearts: number;
  xp: number;
  streak: number;
  currentLessonProgress: number;
  loseHeart: () => void;
  addXp: (amount: number) => void;
  resetLesson: () => void;
}

export const useGameStore = create((set) => ({
  hearts: 5,
  xp: 0,
  streak: 0,
  currentLessonProgress: 0,
  loseHeart: () => set((state) => ({ hearts: Math.max(0, state.hearts - 1) })),
  addXp: (amount) => set((state) => ({ xp: state.xp + amount })),
  resetLesson: () => set({ currentLessonProgress: 0, hearts: 5 }),
}));
\\\

## 6. AI ENTEGRASYONU (AKILLI ÖĞRETMEN)

### 6.1. Writing & Speaking Değerlendirmesi
Kullanıcı serbest metin yazdığında veya konuştuğunda, backend'deki Edge Function şu prompt'u AI'a gönderir:

**System Prompt:**
> "Sen profesyonel bir İngilizce öğretmenisin. Kullanıcı [Discipline] alanından bir mühendis.
> Kullanıcının cevabını dilbilgisi, kelime seçimi ve mesleki bağlam açısından değerlendir.
> Sadece JSON formatında döndür:
> {
>   'is_correct': boolean,
>   'score': 0-100,
>   'feedback_tr': 'Kısa ve motive edici Türkçe geri bildirim',
>   'correction': 'Varsa düzeltilmiş hali',
>   'tip': 'Bir sonraki sefer için ipucu'
> }"

### 6.2. Dinamik Soru Üretimi (Opsiyonel)
Eğer statik soru biterse, AI'a şu prompt ile yeni soru ürettirilir:
> "Mimarlık İngilizcesi seviye A2 için bir 'Boşluk Doldurma' sorusu üret.
> Konu: 'Construction Materials'.
> Format: JSON { question, options, correct_answer }."

## 8. ÖRNEK KOD PARÇACIKLARI (BAŞLANGIÇ İÇİN)

### Örnek: Çoktan Seçmeli Soru Bileşeni (\MultipleChoice.tsx\)
\\\	sx
import React, { useState } from 'react';
import { useGameStore } from '../../store/gameStore';

interface Props {
  question: string;
  options: string[];
  correctAnswer: string;
  onCheck: (isCorrect: boolean) => void;
}

export const MultipleChoice: React.FC<Props> = ({ question, options, correctAnswer, onCheck }) => {
  const [selected, setSelected] = useState<string | null>(null);
  const { loseHeart } = useGameStore();

  const handleCheck = () => {
    if (!selected) return;
    const isCorrect = selected === correctAnswer;
    if (!isCorrect) loseHeart();
    onCheck(isCorrect);
  };

  return (
    <div className="flex flex-col gap-4">
      <h2 className="text-xl font-bold text-gray-700">{question}</h2>
      <div className="grid grid-cols-1 gap-3">
        {options.map((opt, idx) => (
          <button
            key={idx}
            onClick={() => setSelected(opt)}
            className={\p-4 border-2 rounded-xl text-left transition-all \\}
          >
            {opt}
          </button>
        ))}
      </div>
      <button 
        onClick={handleCheck}
        disabled={!selected}
        className="mt-6 w-full py-3 bg-green-500 text-white font-bold rounded-xl disabled:opacity-50"
      >
        KONTROL ET
      </button>
    </div>
  );
};
