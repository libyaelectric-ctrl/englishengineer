Ikon sistemi yenilemesi

Lucide merkezli tutarlı ikon dili

`8.0` kod tabanı incelendi. Mevcut sistem Lucide React kullanıyor; iyileştirme, emoji/string ikonları ve elle çizilmiş navigasyon SVG'lerini aynı stroke, radius, boyut ve semantik adlandırma sözleşmesine taşıyor.

Sistem sözleşmesi
Kütüphane `lucide-react`; özel SVG yalnızca grafik/ürün diyagramı gerektiğinde.
Stroke 1.75-2px optik ağırlık, `currentColor`, yuvarlak uç ve köşe.
Boyutlar Nav 16px, yardımcı 14px, kart başlığı 18px, CTA/toolbar 20px.
Kapsayıcı 4px radius; dolgu `surface-hover`, vurgu sadece aktif durumda.
Creative director kararı

İyi görünen hedef netliği

Bu artefaktın görevi güzel bir ikon vitrininden çok, ürün ekibinin doğrudan uygulayabileceği bir karar sistemi olmak.

Akış
01
Teşhis Emoji/string ikonlar, elle çizilmiş chevron ve tekrar eden rütbe simgeleri sistem borcu yaratıyor.
02
Stil yönü Kompakt mühendislik ürünü: 4px radius, tek stroke, düşük dekorasyon, yüksek taranabilirlik.
03
Kaynak seçimi `creative-director` karar çerçevesi, `brand-spec.md` tokenları, Lucide kütüphanesi ve Open Design export doğrulaması seçildi.
04
Somut düzenleme Sayfa; envanter, değişim matrisi, semantik harita, örnek kabuk ve kod önerisi olarak yeniden okunur.
05
Doğrulama Anti-slop, erişilebilir ikon semantiği, responsive taşma ve render kontrolleri kapanış kapısıdır.
Sıradaki onay
Kaynak koda geçiş `8.0` klasörü bu oturumda salt-okunur bağlam. Uygulama patch’i istenirse aynı eşleşmeler kodda yapılmalı.
Kapsam tercihi Önerilen ilk sprint: sidebar aksiyonları, landing metrikleri ve progress rank ikonları.
Özel ikon gereksinimi Lucide yetmezse yalnızca domain’e özgü tekil kavramlar için Prompt-to-Asset devreye alınır.

Yedek üretim promptları

Lucide yetmezse: Prompt-to-Asset / fal.ai promptları

Aşağıdaki promptlar yalnızca Lucide kütüphanesinde yoksa (domain-özel tekil kavramlar) kullanılır. Tüm promptlar 24×24 viewBox, 1.75-2px stroke, currentColor, round cap/join, 4px radius container standardına uyar.

10 Mühendislik disiplini seti

Lucide karşılığı varsa (yukarıdaki tabloda) prompt gereksizdir. Sadece marka-özel varyant istenirse:

Clean monoline icon set for 10 engineering disciplines: architecture, chemical, civil, electrical, electronics, HSE, industrial, mechanical, mechatronics, software. Uniform 2px stroke, 4px corner radius, minimal detail, single weight, 24x24px viewBox. Vector style, transparent background, professional technical aesthetic. Consistent visual language matching Lucide React stroke style.

5 cohesive rank badges for gamified learning: Grandmaster (crown), Diamond (gem), Platinum (trophy), Gold (medal), Silver (medal). Monoline 2px stroke, 4px radius containers, consistent visual language, Lucide-compatible style. Transparent background. Each badge in a 32x32px rounded square.

Kod tarafında minimum değişiklik

Kaynak klasör salt-okunur bağlam olarak kullanıldı. Aşağıdaki parça, aynı projede uygulanacak çekirdek değişikliğin kısa halidir.

String ikon kaldırılır

`SidebarAction.icon: string` yerine `icon: LucideIcon`; tüm aksiyonlar typed component alır.

Renk hiyerarşiden gelir

İkonlarda raw renk yerine `text-muted-copy`, `text-primary`, `text-success` gibi token sınıfları.

Her yüzeyde tek boy

Sidebar 16px; subsection 14px; kart konteyneri 36-40px. Aynı satırda karma boy yok.

Özel ikon son çare

Lucide semantiği yetmezse önce ürün kavramı tarif edilir; rastgele SVG promptu üretilmez.

import { ChevronDown, ChevronRight, type LucideIcon } from 'lucide-react';

export interface SidebarAction {
  icon: LucideIcon;
  label: string;
  onClick: () => void;
  variant?: 'default' | 'primary' | 'warning';
}

export function Action({ icon: Icon, label, onClick, variant = 'default' }: ActionProps) {
  return (
    <button className="flex items-center gap-2 rounded-[4px] ..." onClick={onClick}>
      <Icon className="h-4 w-4 shrink-0" aria-hidden="true" />
      <span className="flex-1 text-left">{label}</span>
      <ChevronRight className="h-3.5 w-3.5 opacity-45" aria-hidden="true" />
    </button>
  );
}
